# 天空

该引擎将《天际》的白天天空绘制为世界相机周围的渐变圆顶，并对天空进行雾化。
世界来迎接它（`crates/engine/src/sky.rs`，`crates/engine/src/shaders/sky.wgsl`）。这是一个
一天中某个时间的天气：还没有云、太阳、月亮或星星。

## 香草有什么作用

《天际》的天空穹顶是 `meshes/sky/atmosphere.nif`（一种形状，`AtmosphereDome:0`）。它的顶点
颜色是权重，而不是颜色：天空着色器形式
`R * Horizon + G * Sky-Lower + B * Sky-Upper` 来自当前天气的 `WTHR` `NAM0` 颜色，
顶点 alpha 使最低 2.1 度透明。圆顶是阿尔法混合的，
经过深度测试，不写入深度并位于远平面上。它没有起雾。其透明的背后
观众可以看到雾的颜色，它隐藏了陆地和天空之间的接缝。

## 引擎的作用

场景相机现在将天空、背景和雾与 HDR 中的表面合成，然后应用一个共享的
显示变换。请参阅 [L1 颜色管道](color-pipeline.md) 了解域、测试和剩余内容
平价差距。现有的编码天气混合和雾方程仍然是临时的，等待零售
比较；输出修正并不能验证这些假设。

- **颜色。** `SkyPalette` 包含天空上部、天空下部、地平线、雾近和雾远，以及
  线性亮度标度。内置调色板是`SkyrimClear`的日栏（上21,77,117；
  下 60,135,183；地平线125,163,183；雾近35,98,124；雾远 116,168,203，8 位 sRGB）。
  上表为`DOME_MASKS`。两者都是普通常量，因此天气记录可以替代
  他们稍后。
- **渐变。** CPU 将每个表行混合成一种颜色（在 sRGB 中，因为普通混合了 8 位颜色）
  值）并上传 16 行。片段着色器获取视图光线的高度，
  在行之间进行插值，转换为线性并按亮度进行缩放。
- **几何和深度。** 程序半球跟随相机的位置（绝不是其
  旋转）。它的顶点着色器写入剪辑深度 0，Bevy 的无限反向 Z 的远平面
  投影，因此圆顶位于所有其他表面的后面。该材质是 alpha 混合的，未发光，
  未经剔除，没有深度，没有预通道，没有阴影，排序在其他所有后面
  透明绘制。
- **清晰的颜色。** 摄像机清晰到远雾，通过圆顶的透明带显示
  以及地平线以下未绘制地形的地方。
- **Interiors.** `CameraSpace` 表示相机位于外部还是内部单元中
  （`CameraSpace::of(CellKey)`）。在室内，圆顶是隐藏的，相机清除为黑色。
- **哪些相机。** 只有标记为 `SkyCamera` 的相机才具有圆顶和天空清晰的颜色：世界
  相机。材质、纹理和渲染器装置保持不变。

＃＃ 多雾路段

- **香草的作用。** 天气的 `FNAM` 在一天中的每个时间携带四个雾距离，`Near`，
  `Far`、`Power` 和 `Max`。距离 `d` 处的雾量为 `min(Max, t ^ Power)`，其中
  `t = clamp((d - Near) / (Far - Near), 0, 1)`，雾的颜色是天气的雾接近雾
  远色lerp以该量拍摄。 `SkyrimClear`的日栏为`Near` 0，`Far` 80,000，
  `Power` 0.4、`Max` 0.85：0.4 次幂曲线，在 53,289 个单位时达到 0.85 的全部强度
  并留在那里。其夜间柱状图有超过40,000个单位的相同曲线。
- **Bevy 设置。** 发动机不再适合原版的 `FNAM` 功率曲线。它使用贝维的
  基于能见度的大气雾：`FogFalloff::from_visibility_colors`
  `FOG_VISIBILITY = 48_300` 世界单位，Bevy 修订后的 Koschmieder 对比度阈值为 5%。
  在这个距离处，地平线天空下的纯黑色物体失去了 95% 的颜色
  对比。消光色调是 Bevy 的大气雾示例颜色
  `srgb(0.35, 0.50, 0.66)`，因此远处的光失去红色最快。贝维的例子分散
  色调 `srgb(0.80, 0.844, 1.0)` 此处读得太蓝，因此引擎使用去饱和
  `srgb(0.84, 0.89, 0.90)` 同时保持蓝色稍快。
- **颜色。** 雾颜色本身仍然是相机清除的线性雾远颜色，并且
  它是不透明的，因此在全强度雾化地形下，圆顶的透明带和清晰的
  色彩在天边相遇，没有一步。雾中太阳的光芒使用贝维的例子
  暖色定向色调，`srgba(1.0, 0.95, 0.85, 0.5)`，指数为 30。
- **哪些摄像机。** 每个标记为 `FogCamera` 的摄像机：流媒体世界摄像机和素材，
  地形/水、变换边界和渲染器固定相机。 Bevy 将 `DistanceFog` 应用于
  `StandardMaterial` 自行网格化，并通过地形和水着色器进行网格化
  `main_pass_post_lighting_processing`;圆顶的着色器不需要雾，因此圆顶保持不变
  未起雾。水反射相机不会起雾，因为它渲染的水面
  已经起雾一次了。
- **内饰。** 内部单元没有天气影响，因此 `CameraSpace::Interior` 可以消除雾气
  每个 `FogCamera`，因为它隐藏了圆顶。
- **范围。**可见距离比默认相机远平面长，因此地形
  雾化而不是被吞没在流光环内，圆顶的透明带保持
地平线本身是柔和的。先调`FOG_VISIBILITY`；之后才调整色调。

＃＃ 还没有

- 来自世界数据库的天气和气候记录、一天中的时间和天气转变：
  雾的密度和颜色是内置的晴天。外部发射率 (#242) 已存储
  其来源在日出、白天、日落和夜间的颜色，引擎应用白天的颜色。
- 云层（包括第 28 层，横跨地平线的雾带）、星星、太阳和
  眩光、月亮和极光。
- 针对照明表面的校准天空亮度；刻度为 1.0，直到测量
  参考截图。

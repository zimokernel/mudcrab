# 广告牌生成（TexGen 等效）

从转换后的资源中渲染广告牌和 LOD 纹理。取决于
GLB/KTX2 管道，从不在生成的输出上 (TEX-08)。

## 管道

解析完整的模型和材质，应用纹理集替换
参考（TEX-01：具有不同替换的共享几何体可能需要
不同的产品），选择一个配方（缝合对象纹理，渲染
对象纹理、树渲染、草渲染）、计算边界和框架，
渲染线性中间体，生成法线和透明度元数据，
应用输出亮度/材质转换，构建覆盖范围感知的 MIP
链接、压缩和存储维度、数据透视、散列、配方和
依赖关系。

## 框架和元数据

仅确定性取景和照明：无编辑器相机状态，随机
风相，或建筑中的环境暴露 (TEX-03)。储存作物
矩形、投影、物理尺寸和明确的枢轴；一个
裁剪后的广告牌仍种植在源基地（TEX-02）。分辨率
可以根据对象尺寸和配置内的参考比例进行缩放
帽；矩形和二次方策略遵循后端需求（TEX-05）。

## Alpha 和 mips

轮廓覆盖范围必须能够缩小：透明边缘颜色
膨胀和图集间距（TEX-06）。运行时切断默认值为 128
(`material.rs`)，匹配二进制 alpha 约定。 ADR-0009的顶点
阿尔法归一化的存在是因为远处的叶子倒塌了；这个
管道是该修复的长期所在地，其范围由材料语义决定
而不是在整个转换器范围内应用。漫反射和法线图集变换
保持同步；法线从不进行漫反射颜色空间转换
（MAT-05）。联系表将完整模型与正面广告牌进行比较，
侧面、比例、轮廓和照明 (TEX-07)。

## 树

对象路由广告牌优先：全广告牌树 LOD 是有效的低成本
配置（TREE-03）。倾斜、倒下和旋转的树木仍保持其原有状态
变换（TREE-04）； 3D 或混合牙冠仅在之后出现
存在签名匹配的资产，报告了后备，而不是
暗示（TREE-05）。验证轮廓、树干锚固、树冠照明、
和独立的转换（TREE-06）。

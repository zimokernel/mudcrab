# 内部记录诊断

内部阅读器保留其控制台和 `inhouse-reader-diagnostics.json`
小摘要：每个插件的计数和第一个示例。完整诊断
详细信息是可选 `record_diagnostics` SQL 表中的标量行。这个
表是工具来源，并在与源相同的事务中刷新
记录并覆盖历史记录。

有界解码器和适配器示例在每个插件内按固定来源顺序选择，而不是按观察顺序选择。已知的物理源偏移优先于缺失偏移；之后依次按源 FormID、规范 FormID、记录签名、有界字段路径、链接出现位置、阶段、类别、操作、链接值和有界原因排序。字段路径按字典序比较；当有界前缀相同时，以全文摘要打破平局。解码器的 `first_example` 是按同一顺序选出的类别示例。重放合并会保留这些溯源信息；对于没有此信息的手工摘要，则使用确定性的有界文本回退方案。计数和完整事件标识不会改变。完整 SQL 诊断始终按 `(plugin_id, event_key)` 顺序发布，不受摘要选择影响。

诊断事件包括零基供应 `plugin_id`、物理
`source_record_offset`，本机 `source_form_id`，已知时已解析 `form_id`，
记录签名、阶段、字段/链接出现、类别、原因和操作。
将 `plugin_id` 加入到 `record_overrides` 或使用其加载顺序元数据
现有编号合同。跳过的记录可能没有规范的 `records`
行；组/插件成帧失败可能没有记录标识。 NULL 表示
身份不可用，而不是捏造的 FormID。

解码阶段字段出现索引指的是本机框架子记录顺序。
目标验证索引是指幸存的规范字段。延期
准入省略在拒绝字段列表中使用 `omitted` 序数。
阶段和显式出现标签区分这些视图。嵌套成员名称，
数组索引和每字段链接序数区分重复的相等引用。
运行时目标验证链接值是全局的；解码阶段可选链接
值保留其原始的文件相关表示。

操作报告现有恢复决策：`skipped`、`cleared`、
`kept_earlier_version`、`projected` 或显式适配器操作，例如
`unresolved`。观察结果不会改变准入、覆盖顺序、引用解析或地形策略。延迟解码会合并新发现的事件，同时避免重复记录同一物理出现位置在首次处理时产生的诊断。

事件日志使用临时磁盘存储，带有固定的小型 SQLite 缓存。
事件计数没有上限，也没有每个问题的内存列表。场和
原因文本是有界的 UTF-8 字符串；截断在表中是明确的。
诊断身份使用全文，因此两个长原因具有相同的可见性
前缀保持不同。发布按确定的顺序流行，并且
自动替换旧的诊断快照。存储故障有
基础设施故障，无法默默地产生一个表面上完整的
诊断表。

诊断在读取器元数据标识中具有独立的格式版本。
对此可选表的更改不会推进运行时数据库、单元缓存或
资产生产者版本。没有表格的现有包仍然可以使用
运行时消费者。正常的内部导出提供新的表和元数据
身份。其广泛的配置哈希变化；当前每种资产设置
和来源证明保持不变。 Adapter-11 元数据明确识别
精确的adapter-10组合证明，用于未更改的资产设置和独立的证明
合格的生产者。仅元数据迁移保留其完整的原始数据
读取器/模式身份，而不是重新标记这些字节。其他较旧的内部
此显式兼容性对仍然不支持身份。

新的主数据库快照还将现有列表存储为标量子行。
`inhouse_plugin_masters(plugin_id, master_index, master_name)` 保留
创作了具有连续的从零开始的索引的 MAST 订单。 TES4 历史记录行
没有子行表示没有主插件的插件。 `record_overrides` 不再
包含 `plugin_masters` JSON。惰性历史记录阅读器在以下情况下使用子表：
存在并且仍然可以读取旧包中以前的 JSON 列。

`inhouse_unresolved_terrain_textures(form_id, texture_form_id)` 存储每个
其 LAND 所有者的独特非零未解析纹理密钥。
`inhouse_terrain_layers` 保留其原始标准化 `layer_data` BLOB，
单元格和加载顺序，没有以前的 `unresolved_texture_ids` JSON 列。
两个子快照都在来源事务中被替换。运行时
地形选择和缓存编码保持不变。

内部运行时脚本投影也取代了以前的
`scripts.properties_json` 列表，包含标量 `script_properties` 标头和
`script_property_values` 行。父级保留其 `(form_id,script_name)`
键和 VMAD 字节。属性和数组元素索引保留顺序，而
可空标量列保留每个类型化值，包括精确的浮点位。
零类型属性和空数组保留其标题，而没有值行。
此脚本快照刷新属于记录事务；仅存档
捆绑包将这些运行时预测留空。参见[脚本表合约](db-schema.md#9-script-attachments-scripts)。
旧版阅读器输出保留其现有的投影合同。

例如，检查已清除的链接而不解析 JSON 列表：

```sql
选择plugin_id、source_record_offset、source_form_id、form_id、
       字段、出现次数、链接值、原因
来自记录_诊断
WHERE 类别 = '链接' AND 操作 = '已清除'
ORDER BYplugin_id、source_record_offset、字段、出现次数；
```

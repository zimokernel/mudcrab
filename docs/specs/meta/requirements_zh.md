# 构建和转换要求

贡献者的机器在 Mudcrab 上的花费是在带有 NVMe 驱动器的 Windows 桌面上测量的
《天际》特别版及其免费的创造俱乐部内容。以时代为指导：它们取决于
CPU、磁盘以及其他正在运行的东西。

＃＃ 建筑

|步骤|时间 |笔记|
| :--- | :--- | :--- |
| `cargo check --workspace`，第一次|约5分钟|编译 Bevy 和每个依赖项一次 |
| `cargo build --release --bin engine`，第一次|比支票还长|优化的代码生成加上链接时优化 |
|单文件引擎更改，`--release` |约 4-5 分钟 |主要是链接时优化 |
|单文件引擎更改，`--profile quick` |约40秒|没有链接时优化的发布（`cargo build --profile quick --bin engine`）；不用于测量|
|构建文件夹(`target/`) | 20-30 GB | 20-30 GB一起调试和发布配置文件 |

## 转换 Skyrim SE 安装

|项目 |尺寸或时间 |笔记|
| :--- | :--- | :--- |
|游戏的`Data`文件夹|约 15 GB |只读；转换器永远不会写入其中|
|第一次（新的）转换|不重新测量|桌面默认保留原生 BC1-BC7 块，因此纹理需要几分钟； 5.1 小时的数据是完整的 UASTC 运行 |
|输入不变的重新转换 |约30分钟|转换后的资产通过`conversion-manifest.json`复用|
|转换后的输出|不重新测量|仅发布运行时工件（纹理、网格、脚本、数据库、清单）； `vfs/` 和 `.ingestion-cache/` 仍处于暂存状态；持久缓存是 `<output>.assets-cache`，在文件系统允许的情况下硬链接 |
|重新转换期间的可用空间|再次大概输出大小，加上缓存|运行时包从暂存链接并在最后通过旧输出发布；新运行发布后暂存被删除 |

如果没有《Skyrim》，`dummy-content` 夹具（请参阅[贡献](../../../CONTRIBUTING.md)）会构建并
在几分钟内转换一个小型合成游戏。

## 运行引擎

任何支持 Vulkan、DirectX 12 或 Metal 的桌面 GPU 都可以运行该引擎。转换后的纹理保留
KTX2 容器中的本机桌面 BC 块，未映射的格式回退到 Basis UASTC。
